# Cyber Wolf Dashboard: Personal Command Center

A high-fidelity, cyberpunk-themed productivity dashboard designed for the modern digital wolf. This project showcases advanced CSS techniques, real-time data handling, and a deep aesthetic commitment to the "Dark Mage" hacker vibe.

## ⚡ Features
- **Real-time System Clock:** 24-hour precision with holographic date display.
- **Mission Objectives:** Persistent to-do list saved to `localStorage`.
- **Neural Link Monitor:** Simulated system stats (CPU/RAM/NET) with animated telemetry.
- **Atmospheric Data:** Live weather updates (simulated for demo, API-ready).
- **Core Directives:** Rotating philosophical quotes on transcendence and willpower.
- **Cyberpunk FX:** Scanlines, glitch animations, neon glows, and glassmorphism.
- **Easter Egg:** Secret Konami code sequence for "AGI Mode."

## 🎨 Tech Stack
- **Frontend:** HTML5, CSS3 (Grid/Flexbox), Vanilla JavaScript.
- **Design:** Custom CSS scanline filters and keyframe glitch effects.
- **Typography:** Orbitron & Fira Code (Google Fonts).

## 🚀 Setup
1. Clone the repo.
2. Open `index.html` in any browser.
3. For the full experience, use a local server (e.g., `python3 -m http.server`).
